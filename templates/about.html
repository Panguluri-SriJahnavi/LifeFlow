LifeFlow

Vijayawada Blood Bank Management System

CSP Lab Project – Community Service

LifeFlow is a full-stack web application built as a Community Service Project (CSP) by a 3rd Year Data Science student. It aims to digitize and optimize blood bank operations in Vijayawada, Andhra Pradesh, helping save more lives through better inventory management, donor engagement, and predictive analytics.

Key Features
  • Real blood bank branches data of Vijayawada
  • Live inventory & capacity tracking by blood type
  • Appointment & donor management (CRUD + Search)
  • Hospital order tracking (pending / completed)
  • Donor eligibility checker (Indian guidelines)
  • Machine Learning prediction (Random Forest on RFM model)
  • Secure registration & login with roles
  • Beautiful blood-red & black themed UI (Bootstrap 5)
Tech Stack

Python Flask • SQLite • Flask-Login • Pandas • Scikit-learn • Bootstrap 5 • Chart.js • HTML/CSS/JS

Datasets
  1. Blood Bank Branches – 12 real blood banks in Vijayawada with capacity, address, contact.
  2. Sample Branch Data – 50 inventory bags, 50 donors, 50 appointments, 30 hospital orders.
